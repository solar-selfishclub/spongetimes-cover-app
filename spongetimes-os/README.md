## 🚀 사용 방법

### 표지만 만들고 싶을 때
1. `00-design-system.md`에서 디자인 토큰 확인
2. `01-cover.md`의 룰을 따라 표지 제작
3. `04-character-prompt.md`로 캐릭터 이미지 생성

### 전체 캐러셀을 만들고 싶을 때
1. `00-design-system.md` (디자인 토큰 로드)
2. 콘텐츠 유형 선택 → `02-body.md`의 해당 유형 룰 적용
3. `01-cover.md` → `02-body.md` → `03-cta.md` 순서로 슬라이드 구성

### 클로드 코드로 웹앱 구현할 때
모든 문서를 통째로 컨텍스트에 넣고 다음 순서로 구현:
1. 디자인 토큰 → CSS 변수로 변환
2. 슬라이드 컴포넌트 (Cover / Body / CTA) 구현
3. 콘텐츠 유형별 본문 컴포넌트 분기 처리
4. AI 질문 추천 기능 + 캐릭터 프롬프트 생성 기능 통합

## 🎨 캐러셀 전체 흐름

```
표지 (옐로우 풀배경, 매거진 헤더/푸터)
  ↓
본문 N장 (옅은 크림 + 화이트 카드, 유형별 변주)
  ↓
CTA (옅은 크림 + 질문 카드 + 캐릭터 멘트 + 다크 팔로우 카드)
```

## 📋 콘텐츠 유형 4종

| 유형 | 소스 | 슬라이드 수 | 특징 |
|---|---|---|---|
| 현장 기록 | 일요일 워크샵/미니공유회 | 유동적 (10장 이하) | 사진/영상 + 한두 줄 서술 |
| 슬랙 모멘트 | 슬랙 대화 (이모저모) | 유동적 (10장 이하) | 슬랙 캡처 가로 풀 + 코멘트 |
| 참가자 스포트라이트 | 워크샵 줌 녹화본 | **10장 고정** | 6개 조 MVP 컴포넌트 |
| 인사이트/배움 | 스킬 슬랙방 + 발행자 체험 | 유동적 (10장 이하) | BEFORE/AFTER 비교 |

## ⚠️ 운영 원칙

### 절대 하지 말 것
- 외부인 사진을 동의 없이 사용
- 강의 자료 같은 정보 과잉 톤
- 억지스럽게 세련된 척 (넓은 여백만 강조)

### 톤
- 독립 크리에이터/뉴스레터 무드
- 캐주얼하지만 절제됨
- 휴먼 터치 (4명 발행자의 캐릭터 정체성 살리기)

### 발행자
- 4명이 매주 1개씩 발행 (주 2~3건)
- 주차별 자유 선택 (이번 주에 쓰고 싶은 콘텐츠 유형)
- CTA 우측 멘트에 각자 캐릭터 살리기
